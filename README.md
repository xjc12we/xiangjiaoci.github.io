#享交词香角寺社区

##✨ 功能清单
- 登录 / 注册页面
-QQ邮箱注册（验证码需要后端）
- 用户名限制最多5个字
- 管理员面板：删除作品、封禁账号（前端演示）
-支持PNG/JPG图片、MP4视频上传本地预览
- 白天/黑夜主题一键切换
- 右上角设置面板
  - 修改用户名、密码、简介
  - QQ邮箱设置
  - 更多：是否显示性别、是否公开QQ邮箱
-注销账号
- 主页上方搜索框、分类+时间筛选
- 好友聊天模块（前端演示）
- 社区板块浏览他人作品与留言

## ⚠️ 项目说明
这是**纯前端静态原型**，直接打开index.html即可预览。
缺少后端服务，所以下面功能无法在线生效：
1. 邮箱验证码发送
2. 文件永久存储
3.账号数据持久化（刷新页面数据丢失）
4. 实时好友聊天
5. 管理员真实删号、封禁
